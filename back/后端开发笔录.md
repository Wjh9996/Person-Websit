# 2.合并 AI 生成的后端代码（2026-09-02）

把之前 AI 生成的 Spring Boot 后端（原包名 `com.wjh.interview`）合并进本工程（包名 `com.wjh.interviewbacked`）。

## 关键改动 / 踩坑
- **包名统一**：所有 `com.wjh.interview` → `com.wjh.interviewbacked`（含 import、mapper XML 命名空间、application.yml 的 `type-aliases-package`）。
- **补齐依赖**：原工程用了 `@NotBlank/@Email/@Valid`（需 `spring-boot-starter-validation`）、BCrypt（`spring-security-crypto`）、JWT（`jjwt-api/impl/jackson 0.12.6`）。
- **Spring Boot 4.0 差异**：
  - web 依赖是 `spring-boot-starter-webmvc`（不是 3.x 的 `spring-boot-starter-web`）。
  - **Jackson 升级到 3.x，包名从 `com.fasterxml.jackson` 变成 `tools.jackson`**：`ObjectMapper`→`tools.jackson.databind.ObjectMapper`，`TypeReference`→`tools.jackson.core.type.TypeReference`。
  - **没有 `tools.jackson.annotation` 包**，`@JsonIgnore` 不可用；User.password 改为 `transient` 字段来实现「不序列化密码」。
- **Maven 镜像**：本机全局 `settings.xml` 腾讯镜像 `<mirrorOf>*</mirrorOf>` 会拦截 SB 4.0 的 `4.0.9-SNAPSHOT`，已改为 `*,!spring-snapshots` 放行 `repo.spring.io/snapshot`。
- 建表脚本 `schema.sql` 用 `IF NOT EXISTS`，`application.yml` 设 `spring.sql.init.mode: always`，每次启动幂等建表。

## 启动前准备
1. 安装并启动 MySQL，执行：`CREATE DATABASE interview CHARACTER SET utf8mb4;`（本机已建好，可跳过）
2. `application.yml` 已配好 `username: root` / `password: 123456`，连本机 MySQL 直连可用；若你的库密码不同再改。
3. 必须用 JDK 21：`set JAVA_HOME=C:\Program Files\Java\jdk-21`，然后 `mvn.cmd spring-boot:run -Dspring-boot.run.arguments="--server.port=8080"`（在工程目录 `back/InterViewBacked/` 下）。**务必带 `--server.port=8080`**，见第 3 节端口坑。
4. 演示账号 `admin / 123456`。

## 验证结果
- `mvn clean compile` 通过；`mvn package -DskipTests` 通过，产出 `target/InterViewBacked-0.0.1-SNAPSHOT.jar`。
- 注意：完整启动需要 MySQL，本环境未连库，仅做了编译/打包验证。

# 3.真实联调：直连本机 MySQL 成功（2026-09-02）

之前只做了编译/打包验证（未连库）。本次在本机实测启动并连真实 MySQL，全部 17 个接口跑通。

## 启动命令（重要：沙箱会注入端口）
本机 MySQL：`127.0.0.1:3306`，root / `123456`，库 `interview` 已建且已播种（note 7 / resume 3 / user 1）。

`spring-boot:run` 会被沙箱注入 `server.port=4922`，而 4922 被 WorkBuddy 自身占用 → 启动报 `Port 4922 was already in use`。**必须用命令行参数显式覆盖**（命令行参数优先级高于 system property）：

```bat
set JAVA_HOME=C:\Program Files\Java\jdk-21
mvn.cmd spring-boot:run -Dspring-boot.run.arguments="--server.port=8080"
```

# 出现问题

java: -source 1.5 中不支持 lambda 表达式  (请使用 -source 8 或更高版本以启用 lambda 表达式)。版本没处理好

**解决：**

```
<properties>
    <java.version>21</java.version>
    <maven.compiler.source>21</maven.compiler.source>
    <maven.compiler.target>21</maven.compiler.target>
</properties>
```
