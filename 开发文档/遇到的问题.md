## **JSX支持是什么**

JSX（JavaScript XML）是一种JavaScript的语法扩展，它允许你在JavaScript代码中书写类似HTML的标签来描述用户界面。

## **playwright是什么**

Playwright是一个由微软开发的现代化开源Web自动化测试框架。它主要用于端到端（End-to-End, E2E）测试，但也能胜任网页爬虫、自动化脚本等任务。

- 跨浏览器与跨平台：通过一套统一的API，即可驱动Chromium（Chrome/Edge）、Firefox和WebKit（Safari） 三大主流浏览器引擎。它原生支持Windows、Linux和macOS所有平台。
- 多语言支持：提供多种编程语言的官方绑定，包括JavaScript/TypeScript、Python、.NET (C#) 和 Java。
- “弹性”测试，告别不稳定：这是Playwright最显著的优势之一。
  - 自动等待：在执行点击、输入等操作前，Playwright会自动等待元素变为可操作状态，无需手动编写 `time.sleep` 等硬性等待代码。
  - Web优先断言：断言（Assertions）会自动重试，直到条件满足或超时，大大减少了因网络延迟等原因导致的测试偶发失败。
- 强大的隔离性与执行速度：
  - 浏览器上下文：每个测试都在一个独立的“浏览器上下文”（相当于一个全新的浏览器配置文件）中运行，实现完全隔离，且创建开销极低。
  - 并行执行：测试默认并行运行，执行速度非常快。
- 丰富的内置工具链：
  - 代码生成器 (Codegen)：通过录制在浏览器中的操作，自动生成测试代码。
  - 跟踪查看器 (Trace Viewer)：提供测试执行的完整时间轴，包含DOM快照、网络请求、控制台日志等，方便定位失败原因。
  - VS Code扩展：提供直接在编辑器内运行、调试和生成测试的体验。

这样写的目的

你贴出的这段代码是 **Vue Router 的路由懒加载（Lazy Loading）配置**，它的核心目的是 **按需加载**，具体来说：

------

### 1. **减少首屏加载时间**

- 如果不使用懒加载，所有路由对应的组件都会被打包进同一个 `app.js`（或类似的入口文件），导致首屏需要下载大量可能用不到的代码。
- 懒加载通过 `component: () => import('...')` 让该路由的组件只在 **用户实际访问 `/resume` 路径时** 才去下载对应的 JS 文件（即注释中提到的 `About.[hash].js` 这类独立 chunk）。

------

### 2. **实现代码分割（Code Splitting）**

- 构建工具（如 Webpack / Vite）会将这个动态 `import` 识别为分割点，把 `ResumeView.vue` 及其依赖单独打包成一个 chunk。
- 这样项目整体被拆分成多个小文件，浏览器可以并行加载，缓存也更高效（只有修改过的 chunk 需要重新下载）。

# 3.组件开发

![image-20260821181147773](https://gitee.com/jh1659237124/typora-image/raw/master/Image/image-20260821181147773.png)

这个 ESLint 报错是由 `vue/multi-word-component-names` 规则触发的，它要求 Vue 组件的名称**必须由多个单词组成**（如 `MyComponent`），而不能是单个单词（如 `Resume`）。

------

### 为什么会这样要求？

- **避免与原生 HTML 元素冲突**：虽然 `Resume` 不是标准 HTML 标签，但未来 Web 标准可能新增同名元素，自定义组件单名会增加风险。
- **提高代码可读性**：多词命名能更清晰地表达组件的功能和上下文（如 `UserResume`、`ResumeEditor`）。
- **Vue 官方风格指南推荐**：这是 Vue 官方推荐的[最佳实践](https://vuejs.org/style-guide/rules-essential.html#use-multi-word-component-names)，绝大多数项目都默认启用此规则。

![image-20260821184440662](https://gitee.com/jh1659237124/typora-image/raw/master/Image/image-20260821184440662.png)

这个 ESLint 错误是因为你在 Vue 单文件组件（`.vue` 文件）中，`<script>` 标签缺少 `lang` 属性。`eslint-plugin-vue` 的 `vue/block-lang` 规则会检查每个代码块（`<script>`、`<template>`、`<style>`）是否明确指定了语言，以提高可读性和一致性。

------

### 为什么会有这个规则？

- 在 Vue 项目中，`<script>` 默认是 JavaScript，但也可以写 TypeScript（`lang="ts"`）、CoffeeScript 等。显式声明 `lang` 可以让工具链（如编辑器、编译器）正确识别语法，也避免混淆。
- ESLint 插件默认开启了该规则，所以当你不写 `lang` 时就会报错。
