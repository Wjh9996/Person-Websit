# 个人网站（InterViewProject）开发总结

> 本文汇总项目从 0 到全栈打通的完整开发流程、技术架构、遇到的问题与解决方案，以及运行与验证方式。
> 配套文档：`需求分析.md`（需求）、`接口文档.md`（17 个接口 + 实体设计）、`front/开发笔录.md`、`back/后端开发笔录.md`、`.workbuddy/memory/MEMORY.md`（长期记忆/坑点速查）。

## 一、项目概述

- **目标**：做求职用个人网站，首页展示学习成果，三大模块 = 简历 / 笔记 / 用户，最终要能公网访问。
- **技术选型**
  - 前端：Vue 3.5 + TypeScript + Vite 8 + Vue Router 5 + Pinia 4；Markdown 用 `markdown-it` + `highlight.js`；测试 Vitest（jsdom）+ Cypress；规范 oxlint + oxfmt + eslint；Node `^22.18.0 || >=24.12.0`。
  - 后端：`back/InterViewBacked/` 下 Spring Boot **4.0.9-SNAPSHOT** + MyBatis Starter 4.0.1 + MySQL 8.0.36 + spring-security-crypto(BCrypt) + jjwt 0.12.6 + Lombok + validation；包名 `com.wjh.interviewbacked`。
- **目录结构**
  - `back/InterViewBacked/` —— 后端工程（包名 `com.wjh.interviewbacked`，启动类 `InterViewBackedApplication`）
  - `front/InterviewProjectProject/` —— 主前端工程（Vue 3）
  - `需求分析.md` / `接口文档.md` —— 需求与接口设计
  - `front/*.md` —— 前端开发笔记（`开发笔录` / `遇到的问题` / `使用的AI提示词` / `AI工具使用指南`）
  - `.workbuddy/memory/` —— 长期记忆与每日工作日志

## 三、技术架构

### 3.1 前端架构

- **service 层抽象（最关键决策）**：页面**永远不直接 `import src/data/`**，一律通过 `src/services/`（note / resume / user）取数；service 返回 Promise。
  - 后端接入时**只替换这三个文件实现**，页面与 store 一行不改 —— 后续对接真实后端时验证了这一点（页面/store 零改动）。
- **统一 HTTP 客户端** `src/utils/http.ts`：封装 `fetch`，自动注入 `Authorization: Bearer <token>`（token 存 `localStorage` 键 `user-token`），解包 `ApiResult<T>{code,message,data}`，`code!==0` 抛 `ApiError`，401 自动清空登录态。
- **状态管理**：Pinia setup 写法；`useNoteStore` / `useResumeStore` / `useUserStore` 带 `loaded` 标记避免 App 与页面重复请求；`useUserStore.refresh()` 在 App 启动时用令牌调 `/api/auth/me` 恢复登录态。
- **组件与样式硬约定**（用户定下、必须遵守）：
  1. 组件文件名统一带 `Component` 后缀（`NoteCardComponent.vue`、`AppHeaderComponent.vue`）；
  2. 样式三层分离：`global.css` → `common/`（buttons/cards/badges/stats）→ `components/`、`views/`；复用两次以上就往上抽；
  3. `<script>` 必须 `lang="ts"`；组件名多词（`vue/multi-word-component-names`）。
- **Markdown 渲染**：`markdown-it` + `highlight.js`，仅注册 8 种常用语言；关闭 `html:true` 防 XSS；自定义 `heading_open` 注入锚点 id，保证目录与正文标题 id 一致。

### 3.2 后端架构

- **分层**：Controller → Service → Mapper(MyBatis) → Entity；统一返回 `ApiResult<T>`，`code=0` 成功。
- **鉴权**：`JwtInterceptor` + `WebConfig`。GET 读接口公开；写接口 + `/api/auth/me`、`/api/users/**` 需 Bearer 令牌；CORS 放行 `localhost:5180`。
- **安全**：密码 BCrypt 加密（`spring-security-crypto`），登录比对密文；JWT 用 jjwt 0.12.6 签发与校验。
- **数据建模（三表）**：
  - `user`（演示账号 `admin/123456` 由 `DataInitializer` 幂等初始化）
  - `note`（`tags` 存 JSON 字符串）
  - `resume`（`content` 整存 JSON 串，简历为深层嵌套对象，不过度拆表）
- **幂等初始化**：`DataInitializer` 同时播种 **7 篇笔记 + 3 份简历**（seed-resumes.json + Java 文本块），让连接后页面有真实内容；`schema.sql` 用 `IF NOT EXISTS`，`application.yml` 设 `spring.sql.init.mode: always`，每次启动幂等建表。
- **Spring Boot 4.0 差异**：web 依赖用 `spring-boot-starter-webmvc`（非 3.x 的 `spring-boot-starter-web`）；Jackson 升到 3.x。

### 3.3 接口清单（共 17 个，详见 `接口文档.md`）

**笔记 `/api/notes`**（8）：`GET /`、`GET /{id}`、`POST /`、`PUT /{id}`、`DELETE /{id}`、`PATCH /{id}/pin`、`PATCH /{id}/views`、`GET /tags`

**用户**
- 认证 `/api/auth`（4）：`POST /login`、`POST /register`、`POST /logout`、`GET /me`
- 资料 `/api/users`（1）：`PATCH /me`

**简历 `/api/resumes``（4）：`GET /`（快照）、`POST /`、`PUT /{id}`、`DELETE /{id}`

## 四、遇到的问题与解决方案（重点）

### 4.1 前端

| 问题 | 现象 / 原因 | 解决 |
|------|------------|------|
| 组件命名 | `vue/multi-word-component-names` 报单单词组件名 | 统一加 `Component` 后缀 |
| `<script>` 缺 lang | `vue/block-lang` 要求显式声明语言 | 必须写 `lang="ts"` |
| 依赖 peer 冲突 | oxlint 版本冲突导致 `npm install` 失败 | 安装加 `--legacy-peer-deps` |
| `noUncheckedIndexedAccess` | `tsconfig.app.json` 开启后 `arr[0]` 可能为 `undefined` | 索引访问必须判空（如 `list[0] ?? fallback`） |
| 路由顺序 | `/notes/create` 排在 `/notes/:id` 之后时，create 被当成 id | 路由表里 `/notes/create` 必须排在 `/notes/:id` 之前 |
| Markdown XSS | `html:true` 有注入风险 | 关闭 `html`，仅渲染 Markdown；目录锚点用自定义 rule 注入 id |
| service 层设计 | 早期数据在组件内存，刷新即丢 | 抽 service 层落 localStorage（后换 HTTP），页面与 store 解耦 |

### 4.2 后端

| 问题 | 现象 / 原因 | 解决 |
|------|------------|------|
| **Jackson 3 包名变更** | SB 4.0 的 Jackson 升到 3.x，包名从 `com.fasterxml.jackson` 变为 `tools.jackson`；`ObjectMapper`/`TypeReference` 分别在 `tools.jackson.databind` / `tools.jackson.core.type` | 全部改包名 |
| **`@JsonIgnore` 失效** | 3.x **没有 `tools.jackson.annotation` 包**，`@JsonIgnore` 不可用 | `User.password` 改为 `transient` 字段实现「不序列化密码」；并移除不存在的 `jackson-annotations` 依赖 |
| **Maven 镜像拦截快照** | 全局 `settings.xml` 腾讯镜像 `<mirrorOf>*</mirrorOf>` 拦截 SB 4.0 的 `4.0.9-SNAPSHOT` | 改为 `*,!spring-snapshots` 放行 `repo.spring.io/snapshot` |
| **Java 编译报 lambda 不支持** | 未正确设 java 版本，报 `-source 1.5 中不支持 lambda` | `pom.xml` 设 `<java.version>21</java.version>` + `maven.compiler.source/target=21` |
| **Java 字符串字面量引号 bug** | `DataInitializer` 一处笔记摘要误用了 ASCII 引号导致编译/运行异常 | 替换为中文引号 |
| **沙箱注入端口冲突（重要）** | 沙箱在 Java 进程注入 `server.port=4922`，而 4922 被 WorkBuddy 自身占用 → `Port 4922 was already in use` | `spring-boot:run` 用命令行参数显式覆盖：`mvn.cmd spring-boot:run -Dspring-boot.run.arguments="--server.port=8080"`（命令行参数优先级高于 system property） |
| **本地 MySQL 连接** | 本机 `127.0.0.1:3306`（账号密码见本地 `application.yml`，未上传仓库），库 `interview` 已建且已播种（note 7 / resume 3 / user 1） | 直连可用，本地 `application.yml` 已配好连接信息 |

### 4.3 联调 / 流程

- **429 限流**：多次重复提问（"整理接口""mysql"）触发服务端 429，需降频重试。
- **残留 mock（收尾阶段发现）**：`AboutView.vue` 仍 `import testResume` 用假数据且文案写着"数据保存在浏览器本地，后端接入后切换"——与已接后端矛盾。改为走 `useResumeStore`（读后端第一份简历，加载中/后端不可用才回退 mock），文案改为"数据由 Spring Boot 后端服务提供"。`NoteEditorView.vue` 的草稿保存原为裸 `window.localStorage`，收口为 `writeStorage('note-draft', …)`。

## 五、验证情况

- **前端**：`vue-tsc --build` 类型检查 0 错误；`vite build` 构建通过；Vitest **9 个页面冒烟测试全绿**（含首页/笔记/详情/登录/关于/简历/编辑器等，`fetch` 已桩，无需真后端）。
- **后端**：`mvn clean compile` 通过；`mvn package -DskipTests` 通过（产出 30MB jar）；真实启动连本机 MySQL 成功（Tomcat on 8080）。
- **端到端联调（全部通过）**：
  - 直连 `GET /api/notes/tags`、`GET /api/resumes` 返回真实数据
  - 经前端 :5180 的 `/api` 代理转发到 :8080 后端实测成功（链路：浏览器 → 5180(vite) → proxy → 8080(Spring Boot) → MySQL）
  - `POST /api/auth/login`(admin/123456) → 签发 JWT；`GET /api/auth/me` 带 token 返回用户；无 token → 401
  - `POST /api/notes` 新建、`PATCH /api/notes/{id}/pin` 置顶、`DELETE` 均成功

## 六、如何运行

**后端（需 JDK 21 + 本机 MySQL）**
```bat
set JAVA_HOME=C:\Program Files\Java\jdk-21
cd back/InterViewBacked
mvn.cmd spring-boot:run -Dspring-boot.run.arguments="--server.port=8080"
```
> 注意务必带 `--server.port=8080`，避开沙箱注入的 4922 冲突。

**前端**
```bash
cd front/InterviewProjectProject
npm install --legacy-peer-deps   # 有 oxlint peer 冲突
npm run dev                     # 端口 5180
```
浏览器开 `http://localhost:5180`，登录 `admin / 123456`。

**链路**：浏览器 → 5180(vite `/api` 代理) → 8080(Spring Boot) → MySQL。
